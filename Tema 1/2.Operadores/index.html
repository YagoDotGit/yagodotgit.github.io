Operadores

Los operadores es lo que nos permite realizar operaciones entre las variables. Existen muchos operadores diferentes y dependen del tipo de variable que estemos operando. Digamos que cada variable define cómo se van a comportar los operadores con ellas.

No es lo mismo la división de números enteros que la suma o división de números con decimales verdad? Pero el operador que usaremos es el mismo (división).

Operadores aritméticos

Aquí se encuentran los operadores que todos conocemos.

Operador Símbolo
Suma +
Resta -
Multiplicación *
División /
Resto división %

Estos operadores van entre valores. Ejemplo: 3 - 5. Obvio no? Pero el signo menos es peculiar, pues también es un operador unario. Pues también sirve para indicar si un número es negativo. Ejemplo: -3 o -x. En estos casos no hay ningún valor delante.

Muchas veces se deben paréntesis para evitar ambiguedad.
Pues no es lo mismo -3 + 5 que -(3 + 5).

Sobre operador %

Quizá el operador resto de división es el que menos te suena, pero es bastante importante. Si recordamos nuestros días de instituto, el resto de la división es lo que ha sobrado de repartir al dividir.

Si tenemos 6 caramelos y los queremos repartir entre 4 amigos, caen a 1 caramelo por cabeza, es decir, el resultado entero de la división es 1, pero han sobrado 2, por lo que el resto es 2.

En código lo podríamos ver así:

var division: int = 6 / 4   # Esto valdrá 1. Pues es una división de enteros.
var resto: int = 6 % 4      # Esto será el resto de la división (6/4) es decir, 2.

Asignación compuesta

En muchos lenguajes de programación hay formas de acortar cómo se escribe el cambiar el valor de una variable operandola consigo misma.

En lugar de la sintaxis:

x = x <operador> valor

Podemos simplemente hacer

x <operador> = valor

Esto se ve fácil con un ejemplo:

var i: int = 10

i = i + 1

Estamos todos deacuerdo en que este código es válido y lo que hace es aumentar el valor de i de 10 a 11.

Pero podemos en su lugar escribir 

var i: int = 10

i += 1

Esto se usa mucho para escribir de forma rápida que a la variable i cualquiera le incremento su valor en 1 (por ejemplo).

Vale para cualquier operador aritmético.

Operadores booleanos

Estas operaciones en lugar de devolver un número devuelven un booleano. Es decir, true o false.

Operador Símbolo
Comparadores ==, >, <, <=, >=
Not (negado) !
And &&
Or ||
Expresión Significado
a == b a es igual que b
a > b a es mayor que b
a < b a es menor que b
a >= b a es mayor o igual que b
a <= b a es menor o igual que b
a && b a es true y b es true
a || b a es true o b es true

De cumplirse que las expresiones son correctas, la expresión devuelve true, en caso contrario devuelve false.

Operador - !

Este operador es algo diferente porque es un operador unario. Invierte el valor de lo que tenga detrás.

  • ! true - Esto equivale a false
  • ! false - Esto equivale a true

Importante usar paréntesis para evitar ambiguedad.

Pregunta

Cuál es el valor de la siguiente expresión booleana?

!(true && !(1==2))
respuesta false

Comparadores

Los comparadores como puedes suponer comparan variables. Sirven para saber si un valor es mayor/menor que otro, o un valor es igual a otro.

Warning

El comparador para saber si dos variables valen lo mismo es el == que no confundir con el simbolo = el cual sirve para asignar valores a variables.

Ejemplo comparaciones

Cual será el resultado que se imprimirá por pantalla tras la siguiente ejecución?

var a: int = 12
var b: int = 15
var c: int = 12

print(a == b)
print(a == c)
print(a > b)
respuesta false
true
false

Y de esta otra?

var a: int = 12
var b: int = 15

print((a == b) || true)
print((a == b) && true)
print((a == b) || (a != b))
respuesta true
false
true

Asignación

Como es natural podemos asignar operaciones como valor a variables. Ejemplo:

var a: int = 2
var b: int = 5

var c: bool = 2 == 5            # c será igual a false

var d: float = a + b + 3.2      # d será igual a 10.2
