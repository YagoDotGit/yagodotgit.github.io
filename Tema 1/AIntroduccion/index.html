Introducción

Cómo hacer ejercicios básicos

Recordemos el código que hicimos en Preparativos.

extends SceneTree

func _init() -> void:
    print("Hola mundo")

Hemos visto que nuestro código que se ejecuta con el comando godot -s <nombre del script> --headless --quit es el contenido en la función _init(). Esta función es la que es llamada automaticamente al ejecutarse este script. En el futuro veremos que es lo que sucede realmente, de momento quédate con que para ejecutar más lineas de código debemos contenerlos dentro de la función _init.

Puedes hacer todos los ejercicios en nuestro main.gds borrando el contenido de _init() o bien puedes ir creando archivos rollo: ejercicio_1.gds, ejercicio_2.gds. Solo que en este caso el comando para ejecutar cada script será diferente.

Incluso si quieres puedes meter estos archivos en carpetas aunque en el comando de ejecución te tocará poner la ruta al archivo. Ejemplo:

godot -s ejercicios/ejercicio_1.gds --headless --quit

Donde ejercicios es el nombre de la carpeta donde se encuentra el ejercicio 1.

Identación

En GDScript funciona similar a python. Para contener código dentro de un bucle o función debemos escribir las cosas un nivel de identación por encima. Esto se hace escribiendo \tabs, la tecla tabulador, que sería algo así como escribir 4 espacios.

Un ejemplo para visualizar la correcta identación:

Función:
    contenido1
    contenido2
    contenido3

    bucle:
        conetenidoBucle1
        contenidoBucle2

Ejemplo incorrecto

Entonces un ejemplo incorrecto de nuestro código sería: 

extends SceneTree

func _init() -> void:
print("Hola mundo")
MAL MUY MAL. Este código ni siquiera va a ejecutarse. Te animo a probarlo :)

Ejemplo correcto

Vamos entonces a añadir más lineas de codigo a la función _init().

extends SceneTree

func _init() -> void:
    print("Mis disculpas, señor lagarto,")
    print("vengo puesto de manzanilla")
    print("Y con tanto matorral, no veo debajo de mi rodillas")

Creo que todos podemos suponer el output (salida) de este programa.

Comentarios

En la gran mayoría de lenguajes se pueden escribir comentarios, esto son lineas de texto que serán ignoradas a la hora de ejecutar el código, son simplemente anotaciones que dejamos los programadores.

En GDScript se usa el caracter # para escribir un comentario tras este símbolo.

Ejemplo

var a: int = 32

# Comentario: Vamos a hacer una suma
a += 21 # Comentario: Haciendo suma

Puedes poner los comentarios al final de una línea o en una línea vacía.

Sugerencia

Usa los comentarios para explicar algo de tu código y que te sea más facil seguir entendiendo que hace una vez pasado un tiempo.
