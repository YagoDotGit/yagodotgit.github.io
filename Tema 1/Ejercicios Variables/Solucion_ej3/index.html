Solución ejercicio 3

Cómo hacer un swap de varibles. Hay varias formas de hacerlo, la más sencilla de entender es usar una variable auxiliar para guardar el valor de una de las variables a swapear y no perderlo.

extends SceneTree

func _init() -> void:
    var a: int = 12
    var b: int = 43

    print("a = ", a)
    print("b = ", b)

    # Hagamos el swap usando una variable auxiliar
    var aux: int

    aux = a
    a = b
    b = a

    print("a = ", a)
    print("b = ", b)

Otra alternativa es usar operaciones aritméticas, es más pro y no requiere memoria adicional (variable auxiliar).

extends SceneTree

func _init() -> void:
    var a: int = 12
    var b: int = 43

    print("a = ", a)
    print("b = ", b)

    # Hagamos el swap con operaciones
    a = a + b
    b = a - b
    a = a - b

    print("a = ", a)
    print("b = ", b)
