Ejercicio 1

Siguiendo el esquema de código de Preparativos y/o Introducción se pide:

Escribir dentro de _init() el codigo necesario para la creación de 1 variable de cada tipo que hemos visto (int, float, bool, string), con un valor asignado cualquiera, posteriormente mostrarlas por pantalla.

Las variables deberan ser primero creadas, inicializadas y luego impresas por pantalla.

Ejemplo de output (salida de la terminal tras la ejecución del programa):

42
3.14
false
Hola mundo

Recordar godot -s <nombre del script> --headless --quit para ejecutar el código.
