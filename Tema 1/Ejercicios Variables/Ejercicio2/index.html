Ejercicio 2

Similar al ejercicio anterior. Se pide:

  • Crear 2 variables tipo int con sus valores asignados.
  • Crear una tercera variable cuyo valor sea la suma de las dos anteriores, pero deja que godot calcule esta suma no me seas.
  • Imprimir por pantalla siguiendo este formato. 5 + 2 = 7

Esto puede lograrse usando comas en la función de print. print(a, " + ", b, " = ", c)

Ejemplo de output (salida de la terminal tras la ejecución del programa):

124 + 1 = 125

Recordar godot -s <nombre del script> --headless --quit para ejecutar el código.
