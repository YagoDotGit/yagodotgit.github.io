Variables

La programación es enrealidad un proceso de leer datos y hacer operaciones y devolver un resultado. Los principales elementos con los que operar son nuestras variables. Esto son cajitas donde guardamos numeros. Ademas literal.

Basic built-in types

En GDScript hay muchos tipos de variables, pero las variables simples (tipos simples de datos) solo hay 3.

  • bool - Es una variable que solo puede contener 2 valores: True y False. Se puede entender como un interruptor encendido o apagado.
  • int - Almacena números enteros, esto son los que no tienen decimales.
  • float - Almacena números con decimales.

Crear una variable

Cuando creamos una variable, esta se aloja en la memoria de nuestro ordenador con el valor asignado.

Si en Godot hacemos:

var x: int = 40

Estariamos creando una variable de tipo int con el valor 40 y llamada x. Esto quiere decir que podemos acceder a ella refiriendonos como x.

Si hacemos:

x = x + 2

Cual será ahora el valor de x?

respuesta 42. Efectivamente. Toma una galletita te lo mereces -> 🍪

Alojamiento de una variable

Por debajo de la manta Godot hace más cosas que solo poner una x con un valor. Esto es una abstracción que hacemos en los lenguajes de programación para ser felices programando.

En esta imagen vemos que tenemos una variable numérica con el valor 42. Lo que vemos a la izquierda es la posición de la memoria del ordenador donde se encuentra este número, es algo así como la dirección de tu casa, pero para variables.

En los lenguajes de programación de alto nivel no tenemos que especificar la dirección de memoria de una variable que queremos cambiar, pues les ponemos nombres y ya. En nuestro ejemplo habiamos llamado a la variable x y Godot solito sabe cuál es la dirección de memoria de esta variable x.

Esta chapa puede no parecer relevante, pero en el futuro veremos tipos de objetos más complejos que estos y su correcto uso parte de entender como se alojan en memoria y que este concepto existe.

Resumen

Tu creas variables y objetos tranquilamente en GDScript, pero debes saber que por debajo de la manta hay un proceso de alojamiento en memoria de estos datos. Para tipos más complejos de datos el proceso puede requerir que tengas en cuenta lo que está pasando por debajo.

Warning

Godot no te dirá nada, pero tu ordenador no tiene memoria infinita, no puedes crear infinitas variables u objetos tranquilamente porque te vas a quedar sin memoria RAM.

Uno debe aprender lo que no hacer probándolo, así que ya veremos ejemplos donde nuestros ordenadores van tirar pantallazo azul :)
