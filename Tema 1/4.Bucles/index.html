Bucles

Los bucles son herramientas importantisimas que nos permiten controlar el flujo del código. Como su nombre te puede indicar, permiten ejecutar ciertas lineas de código las veces que haga falta. Es la mejor idea que podemos aplicar para no repetir código. En programación siempre se prioriza no repetir código ;)

Imagina que quieres escribir todos los números del 1 al 1000 por pantalla. Como poder puedes programar:

print(1)
print(2)
print(3)
...
...
...
print(1000)

Esto es un poco la muerte a pellizcos, no te parece? Podemos conseguir esto de forma muy sencilla con bucles.

Bucle while

while <condicion> : - Mientras se cumpla la condición, lo que haya dentro del bucle se ejecutará una y otra vez.

Esto quiere decir que si la condición es siempre True, jamás se detendrá la ejecución y pues normalmente no queremos eso.

Como podemos usar esta herramienta para escribir los números del 1 al 1000? Pues aquí un ejemplo:

var i: int = 1

while i < 1000:
    print(i)
    i += 1  # Equivale a i = i + 1

print("FIN")

Este código irá escribiendo el valor de la variable i mientras va aumentando de 1 en 1 en cada iteración. Cuando la variable i sea igual o mayor a 1000 entonces el bucle se detendrá y se continuará la ejecución del código, escribieno "FIN".

Nota

También existe el bucle for (otro tipo de bucle) pero el bucle while nos da todo lo que necesitamos, así que de momento este será el único bucle que necesitamos.
