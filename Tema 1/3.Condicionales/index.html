Condicionales

Podemos manejar el flujo de nuestro programa para poder programar comportamientos más complejos que simplemente una secuencia de instrucciones.

Por ejemplo, imagina que quieres saber si un jugador tiene el suficiente dinero como para comprar un item en la tienda. Tiene que haber una forma de controlar que hacer en cada caso de la condición.

If statement

Quizá te suene pues es algo que se encuentra en todos los lenguajes de una forma u otra. En GDScript funciona de la siguiente manera:

  • if <condición> : - Siendo condición un booleano (true/false) o una expresión booleana, (operadores booleanos como los vistos anteriormente).

    En el cuerpo del if, recordemos que con un nivel de tabulacion superior, irá el código que queremos que se ejecute si la condición se cumple, es decir, el valor de <condición> es true.

  • Y también podemos añadir else : - Donde podemos escribir codigo que se ejecutará en el caso contrario, en el que <condición> sea false.

Ejemplo if - else:

saldo = 123
precio_item = 100

if saldo >= precio_item:
    print("Puedes comprar tu item")
else:
    print("ERROR: Saldo insuficiente")

Nota

En realidad <condición> contará como cumplida si el valor de la misma es cualquier número distinto de 0. Y se dará como no cumplida si el valor es 0.

  • 0 equivale a false
  • cualquier numero - {0} equivale a true

Pregunta

Qué se imprimirá por pantalla tras la ejecución del siguiente código?

if 23:
    print("El Helado")
else:
    print("La Sandía")

if 0:
    print("Me da igual")
else:
    if false:
        print("No me gusta nada")
    else:
        print("Me gusta bastante")
respuesta El Helado
Me gusta bastante

Warning

Como vemos en este ejemplo los ifs se pueden anidar. Ten cuidado porque anidar demasiados ifs (ifs dentro de ifs dentro de ifs...) es una señal de que tu código podría haberse diseñado de una forma mejor.
